# Day and night sound mode

Press Start sound mode and allow microphone access. Use HTTPS on the website or localhost. Audio is analysed on the device; it is not recorded or uploaded.

Day lasts 120 seconds of active play. Louder sound raises flight speed and nectar turnaround from 1× to 3×. Each landing still earns one point. At night the background changes, butterflies stop travelling and nectar collection pauses. Quiet butterflies fold their wings to sleep. The sound meter remains visible when the main controls are hidden.

Night ends after 20 continuous seconds below the Quiet setting threshold. Any louder sample resets the timer. The default threshold is 22 on a relative 0–100 sound scale, not calibrated decibels. Adjust Quiet setting to be just above the room’s normal quiet level. The meter smooths readings for display; the quiet test uses unsmoothed readings. End night immediately begins a new two-minute day without changing scores.

Pause, setup dialogs, the win dialog, petting mode and background tabs pause cycle progress. Leaving the tab clears quiet progress. A disconnected or suspended microphone never counts as quiet; restart sound mode to restore input. Stop sound mode and Reset game stop the microphone and restore ordinary daytime play.

Tests cover phase duration, continuous quiet resets, invalid microphone input, repeated cycles, manual night ending and boosted flight/nectar turnaround. Browser checks verified controls and meter layout. Live microphone levels need a room rehearsal.
